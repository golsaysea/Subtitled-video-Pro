# Security Artifact Attestation

## What The Release Workflow Produces

The GitHub Actions release workflow produces:

- `SubtitleComposer-<tag>-windows-x64.zip`
- `checksums.sha256`
- a GitHub artifact attestation for the zip and checksum file
- release notices and dependency license audit files inside the zip
- bundled open-font assets under `fonts/open`

The attestation is generated by `actions/attest@v4`. GitHub signs the
attestation through its OIDC/Sigstore flow and records provenance for the
workflow run that built the artifact.

## Verify A Downloaded Release

Install GitHub CLI, then download and verify:

```powershell
gh release download v0.1.0 -R <owner>/<repo>
Get-FileHash .\SubtitleComposer-v0.1.0-windows-x64.zip -Algorithm SHA256
Get-Content .\checksums.sha256
gh attestation verify .\SubtitleComposer-v0.1.0-windows-x64.zip -R <owner>/<repo>
```

The hash printed by `Get-FileHash` must match `checksums.sha256`.

## What The Attestation Proves

The attestation binds the released artifact digest to:

- the GitHub repository;
- the workflow identity;
- the source ref or tag;
- the GitHub Actions run that produced the artifact.

It does not prove the code is bug-free, malware-free, or legally sufficient by
itself. It is provenance evidence that the artifact came from the configured
GitHub Actions build.

## Release Security Notes

- `settings.json` is ignored and must not be committed or packaged.
- Cloud sync secrets should be provided through `SUBTITLE_COMPOSER_CLOUD_SECRET`
  or local-only `settings.json`.
- The default cloud sync URL should be provided through
  `SUBTITLE_COMPOSER_SYNC_URL` or local-only `settings.json`.
- Rotate any token that was ever committed, staged, pasted, or included in a
  release artifact before public release.
- If repository history has already contained real secrets, use a fresh public
  repository from the sanitized working tree or rewrite history before pushing.
- Keep release dependencies pinned in `requirements.txt` and
  `requirements-build.txt`.
- Keep `fonts/open/open_fonts_manifest.json` and each bundled font license file
  in release artifacts.

## Local Preflight

Before pushing a public tag, run:

```powershell
git status --short
Test-Path .\settings.json
python -m compileall -q .
```

`Test-Path .\settings.json` should print `False` for the public release tree.
